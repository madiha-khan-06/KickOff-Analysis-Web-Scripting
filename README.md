## 📌 Project Overview

This project demonstrates how to perform **web scraping using Python (Pandas)** to collect football data from multiple online sources.

The workflow includes:

* 🔗 Creating dynamic URL structures
* 🌐 Fetching CSV data from multiple links
* 🧹 Cleaning and transforming data
* 📊 Performing analysis
* 📈 Visualizing insights

---

## 🚀 Features

* 🌐 Fetch data from multiple URLs
* 🔗 Dynamic link generation (root + season + league)
* 🧹 Data cleaning and preprocessing
* 📊 Exploratory Data Analysis (EDA)
* 📈 Data visualization using charts
* 📁 Export final dataset

---

## 🧰 Tech Stack

* 🐍 Python
* 📊 Pandas
